# Subaru Outback Wilderness: хроника последних событий

Краткая повестка расследования и полевых проверок: что ломалось, что подтвердили в SSM4, что поменяли в qhub.kz. Детальная техсправка — в [`subaru-12-column-meter-eyesight.md`](./subaru-12-column-meter-eyesight.md).

**Автомобили и контекст:** Outback VI Wilderness 2.4T, Applied Model **`BTACYR8`**. Работа через **Subaru Select Monitor 4 (SSM4)** и веб-сервис **qhub.kz** (Coding / приборка).

---

## 1. Исходная цель

- Перевод между **США** (°F, mph, `U4…`) и **Канада** (°C, km/h, `C0…`) для Outback Wilderness.
- Желание вводить **ровно ту же 12-колоночную пару**, что и в SSM4, из qhub.
- Отдельно: разобраться, почему при **возврате на `U45D`** у знакомого «вылезли нестираемые» ошибки EyeSight.

---

## 2. Applied Model: буква на 7-й позиции

**Событие:** на этикетке B-pillar указано `BTACYR8`, а при чтении/подстановке в системе иногда фигурировал символ **`B`** на 7-м месте вместо **`8`**.

**Итог:**

- Для 2.4T Wilderness с TR690 + EyeSight корректный 7-й символ — **`8`**, не `B`.
- В пресетах и логике qhub исправлена подстановка Applied Model (ветка `cursor/subaru-applied-model-7th-char-06f7`).

---

## 3. Запись приборки: отказы SSM4 и код 0205

**События на поле:**

- Приборка после уже выполненной перепрошивки: SSM4 — **«Cannot write the Internal Data of the Combination Meter»**.
- Запрос **Input code number** → ввод **`0205`** (бюллетень MC-10169846-0001), затем повтор записи 12 колонок.

**Вывод:**

- `0205` — **не UDS-ключ**, а разблокировка **повторной записи** варианта в меню SSM4 по Combination Meter.
- Цепочка UDS (MET-002 / MET-009 B: `2E 10C2` → `A002` → `A011` → закрытие) реализована в qhub отдельно, с SecurityAccess при NRC 33.

---

## 4. Поиск канадского Option Code (не `C05D`, не `C01D`)

**Проблема:** после перевода друга на канадские единицы попытка откатить или ввести обратно **`C05D`** / **`C01D`** в SSM4 — **Option Code некорректный**.

**Разбор:**

| Код | Результат |
|-----|-----------|
| `C05D` | Нет в таблице SSM4 для `BTACYR8` (US-хвост `5D` не «переклеивается» на `C0`) |
| `C01D` | Не прошёл проверку SSM4 |
| `C0ID` | Обсуждался как «похожий» по опциям; для этой пары в каталоге не рабочий |
| **`C0QF`** | **Принят и записан** в SSM4 |

**Комплектация (ваш запрос):** без подогрева руля, с люком, навигацией, RAB — в **США** это **`U45D`**. В **канадском заводском каталоге** для `BTACYR8` Wilderness 2022–2023 в SSM4 остаётся **`C0QF`** (у канадской сборки другой хвост опций в матрице, в т.ч. подогрев руля на шильдике CA).

**Подтверждение на машине:** после записи **`BTACYR8` + `C0QF`** — успешная прошивка в SSM4; **Dual X-Mode** (два режима снежной грязи) **сохранился**.

---

## 5. Инцидент у друга: B28A0 при возврате на U45D

**Последовательность (восстановленная по симптомам и логам):**

1. Машина с завода: США, **`U45D`** (приборка и EyeSight согласованы).
2. Ранее другим мастером выполнен перевод на **`C0QF`** — при этом **скорее всего обновлены и приборка, и EyeSight** (Work Support → *Selection of Parameter*), т.к. прошло быстро.
3. **Недавняя операция:** в приборку снова ввели **`U45D`**, **EyeSight не трогали**.
4. **Результат:**
   - EyeSight: **`B28A0` Vehicle Model Judgment** (current, не гаснет простым Clear Memory, пока расхождение есть).
   - Сопутствующие: **`C2545`** (EPS), **`B2C22`** (RAB).
5. Повторная запись **`C0QF`** в приборку → ошибки **исчезли** (CAN снова совпал с тем, что записано в камере).

**Причина:** приборка (783) вещает в CAN одну 12-колоночную конфигурацию, стереокамера (787) хранит свою. Несовпадение → **B28A0**.

**Правило на будущее:** при любой смене `U45D` ↔ `C0QF` — **два шага в SSM4:**

1. Combination Meter — 12 колонок.
2. EyeSight → **Selection of Parameter** — те же Applied Model и Option Code → IG OFF 5–10 с → Clear Memory при необходимости.

Чтение текущего значения в камере: **Confirm on Parameter**.

## 6. Почему qhub показывал неверный хвост Option Code

**Жалоба:** при чтении с приборки программа выводила **`C05D`**, хотя «клятвенно» говорилось, что код читается с приборки целиком.

**Факт:**

- С приборки по UDS надёжно читаются **`A002`** (только префикс `U4` / `C0`) и **`A011`** (единицы).
- Суффикс **`5D` / `QF`** в EEPROM **не лежит ASCII-строкой** `U45D`.

**Старая ошибка:** при `C0` qhub **достраивал** хвост из US VIN / пресета → **`C05D`** (недопустимо в SSM4).

**Исправление в коде:** `resolveCanadianOptionCodesForSubaru()` — для `BTACYR8` Wilderness 2022–2023 US `U45D` → CA **`C0QF`**; кнопка возврата на США подставляет **`U45D`**, а не «U4 + чужой хвост».

## 8. Открытые моменты (на момент документа)

- **EyeSight Selection of Parameter** из qhub пока **не автоматизирован** — синхронизацию камеры делают в SSM4 вручную; без этого риск **B28A0** при смене только приборки.
- Для **2024+** Wilderness (`BTAEYR8`) канадский код — **`C0RC`** / альтернативы, не `C0QF` (см. основной MD).

---

## 9. Быстрый итог для техподдержки

1. **Канада, BTACYR8 Wilderness 22–23:** писать **`C0QF`**, не `C05D` / `C01D`.
2. **США:** родной **`U45D`**.
3. **Любая смена региона:** приборка **и** EyeSight одной парой.
4. **B28A0 после U45D:** не «битый EyeSight», а **рассинхрон** — выровнять камеру или вернуть приборку к коду камеры (`C0QF`).
